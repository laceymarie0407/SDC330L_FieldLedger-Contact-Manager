# SDC330L_FieldLedger-Contact-Manager
Java-based contact management application developed for my SDC330L Advanced Object-Oriented Programming course. 
Inspired by my FieldLedger construction management project, this application manages customer, vendor, &amp; employee contacts while demonstrating Java OOP concepts, 
including inheritance, composition, polymorphism, &amp; database integration.

The Contact Manager will organize three types of contacts:
o	Customers: Individuals or companies requesting construction services.
o	Vendors: Companies providing materials, equipment, or services.
o	Employees: Internal employees and their contact information.
Each contact will include a name, associated company, phone number, email, and address.

User Interaction
Users will navigate the application by entering a number from the main menu.
o	Add Contact: Choose Customer, Vendor, or Employee and enter the contact's information.
o	View Contacts: Display all saved contacts in a list.
o	Search Contacts: Enter the first letter of a last name to find matching contacts.
o	Update Contact: Select an existing contact and change information such as a phone number or email address.
o	Remove Contact: Select a contact and confirm that it should be deleted.
After completing an action, users will return to the main menu.
